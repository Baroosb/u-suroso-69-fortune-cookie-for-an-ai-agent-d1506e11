One line, 97 characters: a funny fortune cookie message for an AI agent. The line lives in `entry.txt`; `main.py` copies it byte-for-byte to the output as `/output/entry.txt`. The line was picked by a candidate tournament judged pairwise against the published judge brief.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
